1) Функция main_page :  
Данные для анализа и вывода на веб-страницах — это данные с начала месяца,
на который выпадает входящая дата, по входящую дату.  
Если дата — 20.05.2020, то данные для анализа будут в диапазоне 
01.05.2020-20.05.2020

- Отображает динамическое приветствие, которое через datetime понимает какое сейчас время суток.  
- По каждой карте отображает последние 4 цифры карты, общую сумму расходов и кэшбэк из расчета 1 рубль на каждые 100 рублей  
- Топ-5 транзакций по сумме платежа
- Курс валют на текущий день по API
- Стоимость акций на текущий день по API  
Функция формирует список словарей из необходимых данных и в конце отдает JSON.
(Информация о том какие валюты и акции показывать находится в файле user_setting.json в корне проекта)  
Пример файла user_setting:  
```python

  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]

```

2) Функция events_page  
Функция принимает на вход строку с датой и второйнеобязательный параметр — диапазон данных.
По умолчанию диапазон равен одному месяцу (с начала месяца, на который выпадает дата, по саму дату).  
Возможные значения второго необязательного параметра:  
W — неделя, на которую приходится дата;  
M — месяц, на который приходится дата;  
Y — год, на который приходится дата;  
ALL — все данные до указанной даты.  


Расходы : 
- Отображает общую сумму расходов(отрицательные сумым списаний)
- Отображает основные траты по категориям, отсортированные по убыванию.
Топ-7 самых популярных категорий клиента выводятся в словарь по ключу main,
а остальные уходят в ключ other
- Отображает переводы и наличные, отсортированные по убыванию
- Отображает общую   

Поступления :  

-  Отображает общую сумму поступлений
- Отображает поступления по категориям, отсортированные по убыванию

Дополнительно:  
- Отображение курса валют по API
- Отображение стоимости акций по API  
(Информация о том какие валюты и акции показывать находится в файле user_setting.json в корне проекта)
