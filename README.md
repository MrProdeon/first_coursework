2) Функция events_page

По умолчанию диапазон равен одному месяцу (с начала месяца, на который выпадает дата, по саму дату).  
Возможные значения второго необязательного параметра:  
W — неделя, на которую приходится дата;  
M — месяц, на который приходится дата;  
Y — год, на который приходится дата;  
ALL — все данные до указанной даты.

- Отображает общую сумму расходов(отрицательные сумым списаний)

а остальные уходят в ключ other
- Отображает переводы и наличные, отсортированные по убыванию

-  Отображает общую сумму поступлений

Раздел сервисов для банковского приложения: 

1) profitable_cashback(readed_file  : pd.DataFrame, year : str, month : str) -> str   
Функция для анализа выгоды, полученной от кэшбэка.  
Принимает путь до файла с операциями, год для анализа и месяц для анализа.  
Возвращает JSON, состоящий из словаря, в котором отображены все кэшбэки
по категориям на выбранный год и месяц.  
data — данные с транзакциями;  
year — год, за который проводится анализ;  
month — месяц, за который проводится анализ.  
На выходе — JSON с анализом, сколько на каждой категории можно заработать кешбэка в указанном месяце года.  
Пример использования:
```python
import pandas as pd
from services import profitable_cashback
from utils.views_functions import operations_reader

# Загружаем транзакции из Excel
df = operations_reader("data/operations.xlsx")

# Анализируем кешбэк за октябрь 2023
result_json = profitable_cashback(df, year="2023", month="10")

# Выводим результат
print(result_json)

>>>
{
    "Продукты": 1200,
    "Транспорт": 350,
    "Развлечения": 500
}

```

2) investment_bank(month: str, transactions: list[dict[str, Any]], limit: int) -> float | str  
Позволяет копить через округление ваших трат.

Можно задать комфортный порог округления: 10, 50 или 100 ₽.  
Траты будут округляться, и разница между фактической суммой трат по карте и суммой округления
будет попадать на счет «Инвесткопилки».  
Пример

Вы настроили шаг округления 50 ₽.  
Покупка на 1712 ₽ автоматически округлится до 1750 ₽,
и 38 ₽ попадут в «Инвесткопилку».  
Чем активнее расплачиваетесь картой, тем быстрее копятся деньги в копилке.  

Пример использования:  
```python
from services import investment_bank

# Список транзакций (пример)
transactions = [
    {"Дата операции": "2023-10-05", "Сумма операции": -1712},
    {"Дата операции": "2023-10-07", "Сумма операции": -835},
    {"Дата операции": "2023-10-10", "Сумма операции": -120},
    {"Дата операции": "2023-10-12", "Сумма операции": -2490},
]

# Рассчитываем, сколько денег попадет в "Инвесткопилку" за октябрь 2023
# с шагом округления 50 ₽
invested_amount = investment_bank("2023-10", transactions, limit=50)

print(f"В Инвесткопилку удалось отложить: {invested_amount} ₽")

>>> 138
```

1) get_correct_dataframe(transactions: pd.DataFrame,date: Optional[str] = None) -> pd.DataFrame  
Функция для приведения всех датафреймов к одному типу, а именно с нужными датами
и только расходы, без доходов.  
Нужная дата - это последние 3 месяца до указанной даты. А если дата не указана,
то последние 3 месяца от сегодняшнего дня.  

```python
import pandas as pd
from reports import get_correct_dataframe

# Пример исходного датафрейма
data = {
    "Дата операции": ["2023-07-01", "2023-08-15", "2023-10-05", "2023-10-10"],
    "Описание": ["Продукты", "Транспорт", "Кинотеатр", "Ресторан"],
    "Сумма операции": [-1200, -350, -800, 1500],  # Положительное число — доход, отрицательное — расход
    "Категория": ["Продукты", "Транспорт", "Развлечения", "Доход"]
}

df = pd.DataFrame(data)

# Фильтруем датафрейм за 3 месяца до указанной даты
filtered_df = get_correct_dataframe(df, date="2023-10-10")

print(filtered_df)
>>>
```

```python
df = pd.DataFrame(data)
```

9) get_expenses(operations : pd.DataFrame, date_start: datetime.datetime | None, date_end: datetime.datetime | None) -> dict
Функция для получения информации о расходах в указанном датафрейме.  
На вход получает путь до excel файла с информацией об операциях, дату начала для анализа информации
и дату конца для анализа информации из датафрейма.

    Формирует информацию по разделам:
    1) Об общей стоимость расходов
    2) О 7 наиболее затратных категориях
    3) Если категорий больше 7, то всё что дальше седьмой, суммируется и формируется раздел "Другое"
    4) Переводы и наличные, отсортированные по убыванию

Соединяет всю эту информацию и возвращает словарь, для дальнейшего формирования JSON.  

```python
from utils import get_expenses
import datetime

df = operations_reader("../data/operations.xlsx")
date_start = datetime.datetime(2025, 8, 1)
date_end = datetime.datetime(2025, 10, 31)

expenses = get_expenses(df, date_start, date_end)
print(expenses)  
# {
#   'total_amount': 10250,
#   'main': [
#       {'category': 'Продукты', 'amount': 5000},
#       {'category': 'Рестораны', 'amount': 2500},
#       {'category': 'Транспорт', 'amount': 1500}
#   ],
#   'other': 1250,
#   'transfers_and_cash': [
#       {'category': 'Переводы', 'amount': 1000},
#       {'category': 'Наличные', 'amount': 250}
#   ]
# }

```

10) get_incoming_operations(
    operations: pd.DataFrame, date_start: datetime.datetime | None, date_end: datetime.datetime | None
) -> dict  

Функция для получения информации о поступлениях в датафрейме.  
Принимает на вход путь до датафрейма, дату начала анализа и дату конца анализа.  

Формирует информацию об общей сумме поступлений и раздел "Основное", в котором сумма
по категориям "Наличные" и "Переводы" отсортирована по убыванию.

Возвращает словарь, который в основной функции будет использован для формирования JSON.

```python
from utils import get_incoming_operations

df = operations_reader("../data/operations.xlsx")
date_start = datetime.datetime(2025, 8, 1)
date_end = datetime.datetime(2025, 10, 31)

incoming = get_incoming_operations(df, date_start, date_end)
print(incoming)  
# {
#   'total_amount': 15000,
#   'main': [
#       {'category': 'Зарплата', 'amount': 12000},
#       {'category': 'Переводы', 'amount': 3000}
#   ]
# }

```
