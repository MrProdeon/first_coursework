# Bank Analytics — аналитика банковских транзакций

CLI-приложение для анализа личных финансов по выписке из банка (Excel). Строит для пользователя главную страницу с балансом и кэшбэком, сводки по категориям расходов/поступлений, находит выгодные категории для кэшбэка, считает накопления через «инвесткопилку», ищет операции по номеру телефона или переводы физлицам, а также выгружает отчёты в Excel — плюс подтягивает live-курсы валют и цены акций через внешние API.

## Функционал

**Главная страница (`src/views.py :: main_page`)**
- Динамическое приветствие в зависимости от времени суток («Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи»)
- По каждой карте — последние 4 цифры, сумма расходов за месяц и кэшбэк (1% от суммы трат)
- Топ-5 самых крупных транзакций месяца
- Текущий курс валют и цены акций (список тикеров берётся из `user_setting.json`)

**Страница событий (`src/views.py :: events_page`)**
- Гибкий период анализа: неделя (`W`), месяц (`M`), год (`Y`) или весь период (`ALL`)
- Расходы: общая сумма, топ-7 категорий по убыванию + агрегированная категория «Другое», отдельно переводы и наличные
- Поступления: общая сумма и разбивка по категориям
- Курсы валют и цены акций за тот же список тикеров

**Сервисы (`src/services.py`)**
- `profitable_cashback` — сколько кэшбэка можно получить по категориям за выбранный месяц/год
- `investment_bank` — расчёт суммы, которую можно накопить через «инвесткопилку» при округлении трат вверх до заданного лимита
- `simple_search` — полнотекстовый поиск по описанию/категории операции (regex)
- `phone_number_search` — поиск операций, в описании которых указан номер телефона
- `remittance_search` — поиск переводов физическим лицам (по паттерну «Имя Фамилия.»)

**Отчёты (`src/reports.py`)**
- `spending_by_category` — траты по конкретной категории за последние 3 месяца до указанной даты
- `spending_by_weekday` — средние траты по каждому дню недели за последние 3 месяца
- `spending_by_workday` — средние траты по рабочим/выходным дням за последние 3 месяца
- Декоратор `write_to_file` оборачивает любую из отчётных функций и сохраняет результат в `.xlsx`

**CLI (`main.py`)**
Интерактивное консольное меню с разделами «Главная», «События», «Отчёты», «Сервисы» — обвязка над функциями выше.

## Архитектура и технические решения

- **Слоистая структура**: `utils` — низкоуровневые операции (чтение Excel/JSON, HTTP-запросы к внешним API, преобразование дат); `src/views.py` — сборка данных для «страниц» приложения в JSON; `src/services.py` и `src/reports.py` — самостоятельные аналитические функции над `pandas.DataFrame`; `main.py` — точка входа с текстовым меню, которое дергает перечисленные слои.
- **Работа с данными**: вся аналитика построена на `pandas` — группировки (`groupby`/`agg`), фильтрация по датам, сортировки. Функции принимают либо `DataFrame`, либо список словарей (для сервисов, которым удобнее работать с сериализуемыми структурами), и на выходе отдают JSON-строку (`json.dumps`), что позволяет использовать их как готовый API-слой для фронтенда.
- **Декоратор для отчётов**: `write_to_file` в `src/reports.py` — классический декоратор с параметром (принимает имя файла), который оборачивает любую отчётную функцию, парсит её JSON-ответ обратно в `DataFrame` и сохраняет в `.xlsx` через `openpyxl`.
- **Интеграция с внешними API через `requests`**:
  - курсы валют — публичный JSON-API [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/), без авторизации;
  - цены акций — [API-Ninjas Stock Price API](https://api-ninjas.com/api/stockprice), авторизация по ключу в заголовке `X-Api-Key`, ключ хранится в `.env` и подгружается через `python-dotenv`.
  - Список валют/тикеров для запроса не захардкожен, а читается из `user_setting.json`, что позволяет каждому пользователю настроить свою выборку без изменения кода.
- **Логирование**: в каждом модуле (`utils/functions.py`, `src/services.py`, `src/reports.py`) настроен собственный `logging.Logger` с `FileHandler`, пишущий в отдельный файл в `logs/` (`functions.log`, `services.log`, `reports.log`). Логируются вход в функцию, ключевые шаги обработки и все перехваченные исключения.
- **Обработка ошибок**: все функции, работающие с внешними данными (файлы, HTTP, парсинг дат), оборачивают логику в `try/except`, логируют ошибку и возвращают безопасное значение по умолчанию (пустой JSON/список/`None`) вместо падения всего приложения.
- **Типизация**: код полностью аннотирован (`mypy` в строгом режиме — `disallow_untyped_defs`, `warn_return_any`), используются `pandas-stubs` и `types-requests` для типов сторонних библиотек.

## Стек технологий

- `Python 3.12`
- `pandas` — обработка и агрегация табличных данных
- `openpyxl` — чтение/запись `.xlsx`
- `requests` — интеграция с внешними REST API
- `python-dotenv` — загрузка переменных окружения из `.env`
- `pytest`, `pytest-cov` — тестирование и покрытие кода
- `Poetry` — управление зависимостями и окружением
- `mypy`, `flake8`, `black`, `isort` — статическая типизация и линтинг

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/MrProdeon/bank_analytics.git
   cd bank_analytics
   ```

2. Установите зависимости через Poetry:
   ```bash
   poetry install
   ```

3. Создайте файл `.env` на основе `.env_template` и укажите свой ключ от API-Ninjas:
   ```
   APININJAS_KEY=your_api_key_here
   ```
   Ключ нужен только для получения цен акций ([получить ключ](https://api-ninjas.com/api/stockprice)); без него курсы валют по-прежнему будут работать.

4. При желании настройте список отслеживаемых валют и акций в `user_setting.json`:
   ```json
   {
     "user_currencies": ["USD", "EUR"],
     "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
   }
   ```

5. Положите файл с банковской выпиской в `data/operations.xlsx` (или используйте тестовый файл, если он уже есть в репозитории).

6. Запустите приложение:
   ```bash
   poetry run python main.py
   ```
